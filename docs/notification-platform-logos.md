# Identificação visual das plataformas — NISTI Notificações

O painel administrativo e o monitor da expedição usam logos vetoriais **locais** da pasta `public/platform-logos/`. A tela da expedição usa dimensão maior para leitura à distância. Três filas (Mercado Livre Antigo, Novo e Mercado Livre) compartilham o mesmo símbolo, mas continuam exibindo nomes e dados diferentes. Se um arquivo não carregar, a interface preserva um marcador textual com siglas e o nome completo da plataforma.

A inclusão de arquivos no repositório não significa vínculo ou endosso comercial. A interface não carrega imagens de servidores terceiros durante a operação.
